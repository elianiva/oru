# Frontend plugins contribute submodels to host-owned slots over RPC bundles

Chat-ui extracts as an outsider plugin proving the seam: per-surface slot kinds with versioned plain-data props, tsdown content-addressed UI bundles served by the host and reconciled by generation in the app, host defaults plus `ui.slots.*` startup-only overrides, loud first-wins duplicates. The browser-side import-list shortcut (option A) was rejected so the presentation facet stays a real client of the host process.
